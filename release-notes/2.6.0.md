Desktop app for the stream PC (Windows 10/11, 64-bit).

**Download:** `Zoom-Stream-Automation-Setup-2.6.0.exe`. Installs a new PC, or upgrades the installed app; settings and pairing are kept.

**New in 2.6.0**
- The website is now called **Stream Automation** (https://stream-automation-bkvastrapur.web.app); the app's texts use the new name.
- Several systems with one login: pair each PC (Admin → Add a PC, one code per PC). With two or more, the system name in the website header becomes a dropdown; buttons, live screen and settings act only on the selected system.

**Since 2.5.2:** works with Zoom's new "Livestream" tile; the Zoom window is reliably brought to the front when browser windows are open.

Upgrade: open the app → **Update** → **Download & install**.
